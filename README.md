# riskly-app
## Indicatori TradingView

- `indicatori/correlazioni.pine` — sotto il grafico mostra le ultime candele degli strumenti correlati (default: AUDUSD, NZDUSD, EURUSD, XAGUSD, XPTUSD, DXY) sulla stessa scala, con la correlazione ρ rispetto al simbolo del grafico. Si incolla nel Pine Editor di TradingView.
